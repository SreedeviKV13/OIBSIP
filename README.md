# Isolde — Fashion & Lifestyle Landing Page

**OIBSIP Web Development Track — Level 1, Task 1**

A static landing page for a fictional slow-fashion linen brand, built to
practice foundational HTML/CSS layout skills.

## Tech Stack
- HTML5
- CSS3 (Flexbox + Grid, no JavaScript)
- Google Fonts (Cormorant Garamond, Manrope)

## Features
- Sticky navigation bar
- Hero section with headline, subheadline, and CTA
- Collection grid, editorial story section, and press quotes
- Fully responsive layout (tested down to mobile width)
- Custom color palette applied via CSS variables

## How to view
Open `index.html` in any browser.
